The approved plan builds a source-based reinforcement research package on conditional policies, explicitly addressed credit, scoped state, and ordered interactions. Its API and CLI expose complete learned state while games preserve their source-defined observation limits.

The runtime implements the concrete mechanisms in these milestones. Canonical source profiles requiring original-paper decisions remain gated. Qualitative mechanisms and later dynamics retain catalogue entries and required operational fields.

## Structural contracts

- A table stores stable option identities, float64 propensities, a response mechanism, and any current assignment or reference point.
- An observation is passed separately from its table-binding context.
- Feedback carries success and payoff independently and addresses state directly. Decision occurrences provide optional origins.
- Nature, noise, schedules, completion, and task construction use labeled random requests.
- Invention records provisional identities and commits or rolls back dependent state under its profile.
- Frozen templates receive no adaptive updates. Fan-out reuses one upstream invocation.
- Inquiry, dialogue, phases, and nested tasks explicitly select their timing and persistence boundaries.
