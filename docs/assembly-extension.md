# Assembly, coadaptation, generalization and conflict

The common object of study is an acquired organisation of decisions. A Model
specifies its causal opportunities: observations, actions, participation,
feedback, and adaptive rule. A System holds the dispositions acquired through
those opportunities. An Experiment arranges phases in which that organisation
forms, is released from a constraint, is copied, or is reused in a larger task.
The Run retains the declaration and the acquired state at each endpoint.

This makes transformation an experimental operation. A carry phase preserves
acquired state and random generators; a compose phase binds exported components
to explicit interfaces. Changing trainability preserves dispositions while
changing which modules can receive reinforcement. The [phase workflow](experiments.md)
describes these operations and their TOML declarations. Exported components
record the source checkpoint, retained rows, transforms and policy evaluation.

## Why these studies

The lifecycle study asks whether acquired organisation survives release and reuse.
Matched source branches isolate changes in trainability or the released constraint.
Learned NAND exports retain imperfect conventions, allowing transfer success to be
interpreted alongside the component's measured competence. Freezing imported
components tests reuse; coadaptation additionally requires a kernel that actually
credits those components. Thawing a module alone does not add a feedback path.

The LaCroix study asks how information access and relevance constraints shape joint
assembly. Stipulated roles, role-free relevance, and full-observation/fixed-role
control distinguish these changes. The source predicate checks the decoded pair
in the both-context case, including pairs that compute the same Boolean output.

The generalization study asks how reinforcement neighbourhoods affect discrimination.
Binary alpha=0 isolates local reinforcement; alpha=1 keeps the rows identical,
with exact expected payoff 1.5 under the uniform two-state problem. Intermediate
alpha tests partial coupling. Gaussian widths 0, 0.5 and 2 compare local and broader
updates on a declared twenty-state finite line. Updates are unnormalised, so width
changes both the spread and total reinforcement; claims about spread alone require
an additional matched-total-reinforcement control. Exact reward, normalised reward
and exact-match accuracy answer different questions here.

The conflict study separates three quantities: local reinforcement, participant
utility and scalar task success. It asks whether useful coordination persists as
utilities diverge and whether learning and population dynamics approach different
organisations. The SCOD lambda grid is a declared utility mixture, with lambda=0
recovering the common-interest kernel. The costly-signalling fixtures first test
analytically known payoffs and equilibrium residuals. Learning runs start from their
own specified propensities and are a separate comparison.

All initial declarations use seeds 0, 1 and 2, 100 learning encounters, or one unit
of evolutionary time. These are integration smoke studies. They establish that
resolved configurations execute and retain interpretable endpoints. Larger studies
should first declare a longer horizon, more seeds, endpoint measures and stopping
rules, and preserve the original smoke receipts. Report independent-seed uncertainty
and actual native clocks; an encounter is not equivalent to one unit of ODE time.

## Further cases

The source register retains a roadmap for category formation, bargaining and
inequity, iterated learning, naming conventions, ecological feedback, and innovation.
Their place in this kit depends on an explicit assembly or transformation mechanism:
what organisation is acquired, which constraints change, and how its history can be
carried into a new context. This criterion keeps Barrett's assembly question at the
centre while admitting useful comparison games.

The present material interpretation lives in causal organisation and acquired
state: each feedback event addresses a decision, each component has an interface,
and each transformation records what it carries. Chemical realisations can implement
such interfaces through the existing toyLIFE apparatus. New mappings require their
own observation, timing and decoding specifications; multicellular organisation
remains a later extension.
