# Chemical-controller task protocols

These sixteen protocols are deliberate task variants inspired by the repository's games. Their finite observations, chemical timing, and scores define the experiments described here. The original signaling modules, invented vocabularies, and urn learning mechanisms remain documented in [the game sheets](games/signaling.md), [transfer tasks](games/transfer.md), [computation tasks](games/computation-discourse.md), and [adaptive learning](games/adaptive-learning.md).

A task declares scalar observation domains and action labels. The apparatus translates each currently observed field into ligands. An omitted field contributes zero ligand dose. Integer binary fields default to presence encoding, with `cue` and `stimulus` using distinct identities for their alternatives. Food `0` therefore supplies no food ligand. All episodic tasks include an explicit `reward="none"` baseline ligand during ordinary phases. A choice produces a score in `[0,1]` and a separate one-update nonacting feedback phase with reward `0.0` or `1.0` (habituation supplies its configured feedback control). That observed feedback can influence chemistry; the task applies no numeric learner update. World state retains scores, schedules, and hidden outcomes separately from observations.

Static cases each receive a fresh controller evaluation. Cases carry their exact input probability and an expected reward for every action. Thus stochastic static tasks use exact expected reward rather than one sampled outcome. Episodic phases preserve controller state, advance chemistry for their declared duration (or the configured response updates when duration is unspecified), then read an action when the phase acts. A zero-duration read uses the existing chemical readout. These protocols measure the resolved apparatus and timing together.

| Task | Inputs and actions | Distribution, sequence, and score |
| --- | --- | --- |
| `classification` | `stimulus=0..size-1`; actions with the same labels | Uniform stimulus, identity classification; default size 2. Score 1 for matching the stimulus. |
| `boolean` | Binary `x,y`; actions 0,1 | Four equiprobable inputs. Truth table indexed by `2*x+y`, default NAND `[1,1,1,0]`. Score 1 for the specified output. |
| `context` | Binary `a,b,context`; actions 0,1 | Eight equiprobable inputs. Context 0 selects `a`, context 1 selects `b`. Score 1 for the selected bit. |
| `vote` | Three binary votes; actions 0,1 | Uniform hidden true bit. Each vote independently flips it with error probability, default .1. Cases carry the resulting vote-pattern probability; action rewards are posterior correctness probabilities. At zero-probability patterns both rewards are .5 and case weight is zero. |
| `ordering` | Ranks `a,b=0..size-1`; actions less,equal,greater | Default size 7, all 49 ordered pairs uniform. `train_pairs="adjacent"` restricts training to the 12 directed neighboring pairs. `held_out_cases` returns the 30 nonadjacent unequal pairs with normalized uniform weights. The seven equality pairs belong only to the full distribution. Score 1 for the true relation. |
| `addition` | Cardinalities `a,b=0..maximum`; sum actions `0..2*maximum` | Uniform ordered input pairs, default maximum 5. Score 1 for `a+b`. |
| `sum_compare` | `a,b=0..maximum`, comparison `0..comparison_max`; less,equal,greater | Uniform triples; defaults 5 and 10. Score 1 for comparing `a+b` with comparison. This directly exposes the component inputs to one controller. |
| `monty_hall` | Empty observation; stay,switch | Exact action rewards `[1/3,2/3]`. A uniform prize and initial door choice are assumed; the host always opens an eligible unchosen goat door. The task compares the two final policies directly. |
| `delay` | Two cue identities; actions 0,1 | Uniform hidden bit shown for `cue_updates` (default 8), then absent for `delay` updates (default 8), then a zero-duration choice with no cue. Score 1 for the original identity. A zero delay retains the two explicit nonacting phases. `cue_mode="informative"` is the default; `blank` omits the cue throughout, and `inverted` shows the opposite bit. All three preserve phase durations and score the same original hidden bit. |
| `boxes` | No box-identifying input; two actions | A special box is sampled once per lifetime. `fixed` rewards precisely that box. `random` independently samples success with probability 2/3 at the special box and 1/3 at the other. Default 10 choices with explicit feedback. |
| `bandit` | No option-quality input; three actions | Probabilities default `[.2,.5,.8]`, shuffled among action labels once per lifetime. Each choice receives independent Bernoulli reward at its selected probability. Default 10 choices. |
| `advisers` | No adviser-quality input; seven actions | Probabilities default `.2,.3,.4,.5,.6,.7,.8`, shuffled once per lifetime. Choices receive independent Bernoulli correctness feedback. Default 10 choices. Adviser reliability is an explicit synthetic answer process. |
| `query` | Current answer to attribute `a` or `b`; query_a,query_b,material_0..3 | Two uniform private binary attributes identify material `2*a+b`. Initially neither attribute is observed. Each query reveals only that attribute in the next phase; the earlier answer is omitted after the other query. Chemistry must retain earlier information. Queried attributes become unavailable, and `max_queries` defaults to 2. Any material action terminates inquiry and scores exact identification. Queries carry no numeric reward or cost. |
| `conditioning` | Cue identity 1 when present; food presence; actions 0,1 at the final probe | Default four repetitions with duration 1 per exposure. Paired cycles contain cue+food and blank; unpaired cycles contain cue alone and food alone. Default `order="counterbalanced"` alternates cycle order, with a seed-sampled starting orientation; `cue_food` fixes the listed order and `food_cue` reverses it in both conditions. Both conditions have equal cue dose, food dose, and total training duration, followed by a common `washout=8` blank updates. A final cue-alone probe scores action 1. Probe score measures response presence; a constitutive responder also reaches score 1. Comparing paired and unpaired response under a shared controller is the behavioral test. |
| `habituation` | Cue identity 1 when present; binary response | Default four cue presentations, one update each, with responses and one-update feedback gaps; then eight blank rest updates and one cue recovery probe. Default `feedback="none"` supplies the baseline ligand in every gap. `intact` supplies the suppression score, and `yoked` supplies a predeclared binary `yoked_rewards` list with one entry per scored presentation. `novel_probe=true` appends a distinct cue identity 2 after recovery. Each response scores 1 for action 0 (suppression). Info records each response, initial response, recovery response, optional novel response, and feedback control; the world retains the response trace. A constant-zero controller receives maximum fitness. Decrement and recovery require inspecting the response trajectory and an initially responsive control. |
| `reversal` | Binary cue; actions 0,1 | A hidden binary mapping is sampled once. The rewarded action is cue XOR mapping in the first half and its opposite from trial `trials//2`. Cue is independently uniform each trial; default 10 choices. Each choice receives correctness feedback. |

The query oracle is fixed within each episode and feature values are private until requested. Its restricted observation stream implements information acquisition and retention without the source game's sender/receiver organization. Classification, Boolean, context, ordering, arithmetic, and voting similarly expose direct task inputs to the chemical controller. These choices define derived chemical computation experiments; their success can be reported using the exact case distribution, apparatus, and controller evaluation conditions above.

`TaskInteraction` exposes episodic tasks through the situated protocol with the sole actor `cell`; it converts action labels into the pure task functions' indices. It also exposes metadata for static tasks, whose execution uses `static_cases`. Worlds and NumPy generator states are checkpointable, and transitions copy their input world before changing it. Parameter validation rejects unknown names, malformed finite domains, invalid probabilities, and incompatible phase actions.


## Assay controls and interpretation

For conditioning, compare the same frozen controller and seeds across paired and unpaired schedules, include both fixed exposure orders or the default counterbalanced order, and report a washout-duration series. Counterbalancing is exact over cycles for even repetition counts; odd counts leave one extra orientation and benefit from matched seed replicates. The shared blank interval aligns the immediate pre-probe observation and time, while washout sensitivity measures residual chemical state. A paired/unpaired difference can arise from the schedule's joint chemical dynamics; a mechanistic association account requires further intervention in that state. Response-presence fitness favors a constitutive responder, so retain the individual probe responses for every condition.

For habituation, start with an independently chosen initially responsive controller, freeze its genome, use `feedback="none"`, and retain the initial, repeated, recovery, and optional novel-cue responses. A useful diagnostic trajectory has an initial response, decrement across repeated cues, and response after rest; the novel cue tests response specificity. Novel-cue response also depends on the controller's pre-existing sensitivity to identity 2: measure that sensitivity in separate fresh-controller trials before interpreting the appended probe. The novel probe follows recovery and inherits that additional exposure. Constant silence still maximizes suppression fitness, so this fitness alone selects suppression. Compare intact feedback against baseline gaps and an externally supplied yoked reward trace of identical length to measure feedback dependence. Yoked values are supplied by a separate donor run and remain independent of the recipient's actions; their origin belongs in the study manifest.

For delayed response, evaluate informative, blank, and inverted cues at identical cue and delay durations on the same frozen genome and matched seeds. This compares cue dependence at the same chemical age. Report the hidden-target response by cue condition and delay. A phase-boundary state reset changes the controller's entire chemical state; its effect describes dependence on that intervention.

The assay defaults deliberately change the earlier conditioning schedule by adding counterbalanced order and eight washout updates, and change habituation's observed feedback to the baseline ligand. `conditioning` with `order="cue_food", washout=0` restores the earlier exposure schedule (including a zero-duration blank phase); `habituation` with `feedback="intact", novel_probe=false` restores its earlier observed feedback and cue schedule. These options identify explicit experimental variants.
