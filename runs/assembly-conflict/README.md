# Conflict and coordination

Hypothesis: Divergent utilities change the organisations supported by learning and evolutionary dynamics. Compare the published three-state payoff example, costly-signalling equilibria, and a constructed SCOD utility-mixture grid.

`experiment.toml` retains the full comparison declaration, seeds and budgets.
These first runs are bounded integration checks. See [study rationale](../../docs/assembly-extension.md) for measures, controls, source relationships and larger-study requirements.

Run with `sg run runs/assembly-conflict/experiment.toml --workspace assembly-conflict`.
