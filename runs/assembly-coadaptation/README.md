# Coadaptive composition

Hypothesis: Information access and relevance constraints change which hierarchical organisations can acquire success. Compare stipulated, role-free and full-observation/fixed-role control.

`experiment.toml` retains the full comparison declaration, seeds and budgets.
These first runs are bounded integration checks. See [study rationale](../../docs/assembly-extension.md) for measures, controls, source relationships and larger-study requirements.

Run with `sg run runs/assembly-coadaptation/experiment.toml --workspace assembly-coadaptation`.
